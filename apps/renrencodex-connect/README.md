# renrencodex-connect

[中文](#中文) · [English](#english)

## 中文

`renrencodex-connect` 是人人Codex官方 SSH/原生 TCP 端口连接器。它既随 Desktop 安装，也可以脱离
Desktop 独立运行。连接器只接受 `*.preview.renrencodex.com` 官方预览域名，校验系统信任链和主机名，
要求 TLS 1.3 与 `renrencodex-tunnel/1` ALPN，并且只允许在本机回环地址上建立 TCP 转发。

### 下载与校验

- [Windows x64 ZIP](https://renrencodex.com/downloads/renrencodex-connect-windows-x64.zip)
- [macOS Universal tar.gz](https://renrencodex.com/downloads/renrencodex-connect-macos-universal.tar.gz)
- [Linux x64 静态版 tar.gz](https://renrencodex.com/downloads/renrencodex-connect-linux-x64.tar.gz)
- [SHA-256 校验清单](https://renrencodex.com/downloads/renrencodex-connect-SHA256SUMS)

每个压缩包都包含可执行文件、本文档、MIT `LICENSE` 和 `THIRD_PARTY_NOTICES.md`。下载后应先按照
清单核对 SHA-256；也可以使用 GitHub CLI 核验由公开仓库构建工作流生成的来源证明：

```bash
gh attestation verify <archive> --repo renrencodex/desktop
```

当前无证书发行渠道的 Windows 文件没有 Authenticode 签名，macOS 文件使用 ad-hoc 签名且未经 Apple
公证，Linux 压缩包也没有发行版软件仓库签名。系统可能显示未知发布者或阻止首次运行；只有在确认下载
地址、SHA-256 和来源证明后，才应手动放行。这里的 SHA-256 与来源证明不能替代操作系统代码签名。

### 安装

Windows：解压 ZIP，把 `renrencodex-connect.exe` 放入已加入用户 `PATH` 的目录。

macOS：校验后解压并安装 Universal 二进制；如果 Gatekeeper 因隔离标记阻止这个未公证版本，确认上述
校验均通过后再移除该文件的隔离标记。

```bash
tar -xzf renrencodex-connect-macos-universal.tar.gz
xattr -d com.apple.quarantine renrencodex-connect
sudo install -m 0755 renrencodex-connect /usr/local/bin/renrencodex-connect
```

Linux：压缩包中的 x64 musl 二进制为静态链接版本。

```bash
tar -xzf renrencodex-connect-linux-x64.tar.gz
sudo install -m 0755 renrencodex-connect /usr/local/bin/renrencodex-connect
```

### 使用

SSH `ProxyCommand`：

```bash
ssh -o 'ProxyCommand=renrencodex-connect proxy %h' \
  root@22-<machine-id>.preview.renrencodex.com
```

也可以写入 `~/.ssh/config`：

```sshconfig
Host *.preview.renrencodex.com
  ProxyCommand renrencodex-connect proxy %h
```

把远端 TCP 端口转发到本机回环地址：

```bash
renrencodex-connect forward \
  18471-<machine-id>.preview.renrencodex.com \
  --listen 127.0.0.1:18471
```

使用 `renrencodex-connect --version` 查看版本。连接器与 Desktop 使用同一个 SemVer 和同一份源码；
独立连接器不会自动更新，请从上述固定地址获取新版。

## English

`renrencodex-connect` is the official RenrenCodex connector for SSH and native TCP ports. It is
bundled with Desktop and can also run independently. The connector accepts only the official
`*.preview.renrencodex.com` domain, verifies the operating-system trust chain and host name,
requires TLS 1.3 with the `renrencodex-tunnel/1` ALPN, and binds local forwards only to loopback.

### Download and verify

- [Windows x64 ZIP](https://renrencodex.com/downloads/renrencodex-connect-windows-x64.zip)
- [macOS Universal tar.gz](https://renrencodex.com/downloads/renrencodex-connect-macos-universal.tar.gz)
- [Linux x64 static tar.gz](https://renrencodex.com/downloads/renrencodex-connect-linux-x64.tar.gz)
- [SHA-256 checksums](https://renrencodex.com/downloads/renrencodex-connect-SHA256SUMS)

Each archive contains the executable, this README, the MIT `LICENSE`, and
`THIRD_PARTY_NOTICES.md`. Check its SHA-256 after download. You can also verify the build
provenance generated by the public repository workflow with GitHub CLI:

```bash
gh attestation verify <archive> --repo renrencodex/desktop
```

The current certificate-free channel does not Authenticode-sign the Windows executable. The
macOS executable is ad-hoc signed and not notarized, and the Linux archive is not signed by a
distribution package repository. The operating system may warn about an unknown publisher or
block the first launch. Bypass that warning only after checking the download origin, SHA-256, and
provenance. Checksums and provenance do not replace operating-system code signing.

### Install

On Windows, extract the ZIP and place `renrencodex-connect.exe` in a directory on your user
`PATH`.

On macOS, verify and extract the Universal binary. If Gatekeeper blocks this unnotarized build
because of its quarantine attribute, remove that attribute only after all checks above pass.

```bash
tar -xzf renrencodex-connect-macos-universal.tar.gz
xattr -d com.apple.quarantine renrencodex-connect
sudo install -m 0755 renrencodex-connect /usr/local/bin/renrencodex-connect
```

On Linux, the x64 musl executable in the archive is statically linked.

```bash
tar -xzf renrencodex-connect-linux-x64.tar.gz
sudo install -m 0755 renrencodex-connect /usr/local/bin/renrencodex-connect
```

### Use

Use it as an SSH `ProxyCommand`:

```bash
ssh -o 'ProxyCommand=renrencodex-connect proxy %h' \
  root@22-<machine-id>.preview.renrencodex.com
```

Or add it to `~/.ssh/config`:

```sshconfig
Host *.preview.renrencodex.com
  ProxyCommand renrencodex-connect proxy %h
```

Forward a remote TCP port to local loopback:

```bash
renrencodex-connect forward \
  18471-<machine-id>.preview.renrencodex.com \
  --listen 127.0.0.1:18471
```

Run `renrencodex-connect --version` to inspect the installed version. The connector shares the
Desktop SemVer and source revision. Standalone packages do not update themselves; download newer
versions from the fixed links above.
